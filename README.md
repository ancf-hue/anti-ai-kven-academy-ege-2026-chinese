Добро пожаловать в **Анти-ИИ Квен Академию**! Это бесплатный, полностью автономный (offline-first) интерактивный тренажёр для подготовки к Единому государственному экзамену (ЕГЭ) по китайскому языку 2026 года. 

Проект создан для того, чтобы помочь ученикам **понимать** язык, а не слепо копировать ответы из нейросетей. Мы делаем упор на развитие реальных навыков: распознавание тонов на слух, знание иероглифики, грамматики и умение строить логичные рассуждения.

## ✨ Ключевые возможности

* 🎧 **Раздел "Аудирование"**: Встроенный плеер для общего аудиофайла с имитацией реальных условий экзамена (двукратное прослушивание).
* 🧠 **Тренажёр иероглифов (HSK 1-3)**: Интерактивные карточки с пиньинем и переводом. Кнопка 🔊 озвучивает иероглиф с помощью встроенного в браузер синтезатора речи (Web Speech API).
* 📚 **Тематический словарь ЕГЭ**: Поиск по ключевым словам (образование, экология, культура и др.) с мгновенной озвучкой.
* ⚠️ **Лексические ловушки**: Разбор частых ошибок и различий между похожими словами (например, 看 vs 见 vs 到, 的 vs 得 vs 地).
* ✍️ **Письменная часть (28-29)**: Поля для ввода текста с **живым счётчиком иероглифов**, который меняет цвет в зависимости от соблюдения норм ЕГЭ (150–190 и 160–200 знаков).
* 🎤 **Устная часть (1-3)**: Шаблонные структуры ответов и тайминг для заданий на говорение.
* 📅 **План подготовки на 25 дней** и интерактивный чек-лист для самоконтроля.
* 🔒 **100% Приватность**: Приложение работает полностью в браузере. Прогресс сохраняется в `LocalStorage` вашего устройства. Никаких серверов, трекеров или рекламы.

## 🚀 Как начать использование

1. Скачайте или склонируйте этот репозиторий на свой компьютер.
2. Положите в ту же папку файл с аудиозаписью экзамена и назовите его строго **`audio.mp3`** (без пробелов и кириллицы).
3. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).
4. *Рекомендация:* Для корректной работы синтезатора речи и аудио лучше всего открывать файл через локальный сервер (например, расширение "Live Server" в VS Code), хотя базовый функционал работает и при прямом открытии.

## 🛠 Технологический стек
* **HTML5 / CSS3**: Адаптивный тёмный дизайн (Glassmorphism), удобный как на ПК, так и на смартфонах.
* **Vanilla JavaScript**: Никаких тяжёлых фреймворков (React, Vue). Код лёгкий, быстрый и работает даже на слабых устройствах.
* **Web Speech API**: Для озвучивания китайских иероглифов без необходимости скачивать дополнительные аудиофайлы для каждого слова.
